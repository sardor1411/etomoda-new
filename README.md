# ETOMODA

Modern and responsive e-commerce website built with a focus on clean UI, smooth animations, and a fast shopping experience.

## ✨ Features

* Modern e-commerce interface
* Responsive design for desktop, tablet, and mobile
* Smooth and modern animations
* Product listing and product details
* Category navigation
* Search and filtering
* Shopping cart functionality
* Interactive product cards
* Modern hover and transition effects
* Fast and optimized user experience

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **Framer Motion**
* **ESLint**

## 🚀 Setup Guide

### 1. Clone the repository

Open the VS Code terminal and run:

```bash
git clone https://github.com/sardor1411/etomoda-new.git
```

### 2. Navigate to the project

```bash
cd etomoda-new
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```

Open the URL in your browser.

## 📦 Production Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
